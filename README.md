# 두루온 (Duruon)

영주 관광 DRT 예약 앱 프로토타입입니다. 사용자는 영주역 또는 풍기역에서 출발해 주요 관광지를 선택하고, DRT를 예약한 뒤 탑승 상태와 지난 이용 내역을 확인할 수 있습니다.

현재 버전은 공모전 MVP 시연용 React 웹 앱입니다. 모바일 앱처럼 보이도록 아이폰형 목업 프레임 안에서 동작합니다.

## 핵심 시나리오

### 1. 관광지 선택 후 DRT 예약

1. 로그인
2. 홈에서 출발역 선택
3. 소수서원, 부석사, 무섬마을 중 관광지 선택
4. DRT 호출하기
5. 탑승 시간과 인원 선택
6. 예약 확정
7. 현장 결제 또는 간편결제 선택
8. 내 탑승 화면에서 예약 확인

### 2. 탑승 진행

1. 내 탑승 화면에서 남은 도착 시간 확인
2. `탑승 시작` 선택
3. `하차 완료` 선택
4. 홈으로 이동
5. 완료된 예약이 지난 탑승 내역으로 이동

### 3. 결제수단 등록

1. 마이페이지 진입
2. 결제수단 관리 선택
3. 네이버페이 또는 카카오페이 임시 등록
4. 예약 단계에서 등록한 간편결제 수단 선택

## 구현 기능

- 사용자 로그인 및 임시 회원가입
- 홈 관광지 카드
- 영주역/풍기역 출발 선택
- DRT 예약 화면
- 목적지, 탑승 시간, 인원 선택
- 현장 결제 및 간편결제 선택
- 네이버페이, 카카오페이 임시 등록
- 내 탑승 화면
- 실시간 도착 카운트다운
- 탑승 시작, 하차 완료 상태 전환
- 지난 탑승 내역 이동
- 마이페이지 메뉴 및 상세 패널
- 관광공사 API 프록시 기본 구조

## 기술 스택

- React
- Create React App
- React Leaflet
- Vercel Serverless Function 구조
- `sessionStorage`, `localStorage` 기반 MVP 상태 저장

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 아래 주소를 엽니다.

```text
http://localhost:3000
```

## 빌드

```bash
npm run build
```

## 임시 로그인 계정

```text
아이디: user
비밀번호: demo1234
```

회원가입 화면에서도 임시 계정을 새로 만들 수 있습니다. 현재 회원 정보는 브라우저 `localStorage`에 저장됩니다.

## 환경변수

관광공사 API 프록시를 사용하려면 `.env` 파일에 아래 값을 설정합니다.

```bash
TOUR_API_KEY=your_data_go_kr_service_key
```

로컬 CRA 개발 서버에서는 `/api/tour` 서버리스 함수가 붙지 않습니다. 그래서 로컬에서는 API 호출이 실패할 수 있습니다. 화면에는 기본 관광지 데이터가 표시되도록 처리했습니다.

## 현재 데이터 저장 방식

현재 버전은 MVP 프로토타입입니다.

- 로그인 세션: `sessionStorage`
- 임시 회원가입 정보: `localStorage`
- 간편결제 등록 정보: `localStorage`
- 예약 및 탑승 상태: React state

추후 Supabase Auth와 Postgres로 확장할 수 있도록 구조를 분리해 두었습니다.
